# WO-003 手测清单

使用施工候选，本地运行、模拟分析。此清单供总控评审与独立复核通过后，由用户集中手测一次；自动测试不替代手测。当前候选不部署。

1. 进入开场，再进入“我的岗位”；新建时选“试试示例”，校对后确认。完整报告的条件、未显示项、类型标签和第 2–8 章都能读。
2. 桌面点出处，原文对应行高亮且只出现一根线；滚动后端点仍对齐。再点或 Esc 收起。手机点出处可看原文浮层，“在原文里看”能跳回原文。
3. 选中一段文字点“问一问”，填写问题并获取“示例解答”；也试一次“问这一节”。问题会记在“我的疑问与补充”，先不加入也能找回。
4. 加入报告后成为第 2 版，刷新仍在选中文字所在段落下方；补充保留“你选中的”原句。任职程度、原文、基础判断没有被修改。
5. 修改补充生成第 3 版；撤下需连续两次确认，生成第 4 版。回看第 2、3 版，各自显示当时的补充，旧版本没有提问或修改入口。
6. 切到“面试前速览”，看到重点、出处、依据、“我问过的”、一句话和反问理由。回看旧版本时只汇总当时已加入的补充。
7. 导出报告选择一个旧版本，复制全文确认版本、日期、出处和当时补充正确；不带岗位标记、备注或未加入的草稿。尝试打印／另存 PDF，确认不包含页面操作按钮、备份界面和问答草稿。
8. 返回首页，点“数据与备份”下载 JSON。文件里包括全部岗位、原文、报告版本和疑问；导出后提醒消失。只查看岗位不会催备份；修改备注、标记或删除后会提醒有新改动。
9. 再选择刚才的文件：先看预览，尚未确认前列表不变。选择“合并”，原岗位仍在，同 ID 的岗位以“导入的副本”保留，旧版和补充仍能查看。
10. 用单独的浏览器用户资料／新浏览器导入同一文件，检查岗位、版本、原文与疑问都恢复。不要清理日常浏览器的数据来模拟新浏览器。
11. 若要试“替换”，用虚构测试数据：预览选择替换 → 下一步 → 先导出现有数据 → 确认替换。确认前不变，确认后只剩文件中的岗位；先导出的文件可恢复替换前的数据。
12. 文件截断、非备份 JSON、过新的格式会说明原因，不应改变本机记录。
13. 用键盘尝试标签页左右箭头、版本菜单上下箭头与 Enter、弹层 Tab 循环与 Esc；手机确认正文可读且无横向滚动。

解答失败与注入写入失败由自动测试覆盖，产品不提供隐藏地址开关。真机长按选区、Safari、原生打印和 PDF 保存需在这次手测中确认。
